# Distribuidora CLARITA — Tienda Premium

Página web de ventas con categorías, productos, carrito y pedido completo a WhatsApp **+502 5830-4062**.

**Inicio:** `index.html`  
**Panel:** `admin.html`  
**Instalación y limitaciones:** `docs/GUIA-INSTALACION.md`  
**Servidor opcional y base de datos:** `backend/supabase.sql` + `js/config.js`

**AVISO:** Por ahora no hay precios ni inventarios proporcionados. Se muestran como «por confirmar»; el carrito puede combinar artículos con y sin precio. Sin Supabase el panel de administración es solo local, de demostración, y sus cambios **no se publican para otros visitantes**. Para administración real seguir la guía de instalación.

Nombre, dominio, repositorios, base de datos y contraseñas finales deben quedar a nombre de Distribuidora CLARITA. No se han comprado servicios ni creado cuentas.


### Interacciones de «Así de fácil» (21/10/2026)
- **Explora el catálogo:** muestra todas las categorías y te lleva a los productos.
- **Arma tu pedido:** abre el carrito para cambiar cantidades o volver al catálogo.
- **Confirma por WhatsApp:** abre el carrito y permite completar los datos y enviar el pedido; si está vacío, indica que primero hay que agregar productos.
- **Recibe tus insumos:** abre una ventana con envío nacional y retiro en Cantel. La elección se guarda en el formulario del carrito; también ofrece ubicación de referencia y consulta por WhatsApp.
- No hay cobro en línea ni confirmación automática de stock, costo de transporte o pago.
